# نظام إدارة المعاهد الأهلية

بنيت هذا النظام لإدارة شؤون المعاهد الأهلية من مكان واحد: الطلاب والأساتذة والدورات والاشتراكات والأقساط، مع الرواتب والمصروفات والإيرادات والتقارير المالية. الواجهة كلها بالعربية وباتجاه RTL، لأن المستخدمين الفعليين يعملون بالعربية ولم أرد أن أفرض عليهم واجهة إنجليزية.

الفكرة ببساطة: المعهد يسجّل طلابه ودوراته، يستلم الأقساط، يصرف الرواتب، وفي أي لحظة يعرف صافي ربحه وكم تبقّى له عند الطلاب. حاولت أن يكون كل شيء واضحاً وسريعاً بدون خطوات زائدة.

## أهم الميزات

- لوحة مؤشرات تعطيك صورة سريعة: عدد الطلاب والأساتذة والدورات، الإيرادات والمصروفات وصافي الربح والمبالغ المتبقية.
- إدارة كاملة للطلاب والأساتذة والدورات مع صفحات تفصيلية لكل منهم.
- اشتراكات تدعم أكثر من دورة للطالب الواحد مع إمكانية الخصم.
- استلام الأقساط خطوة بخطوة، وكل دفعة تُطبع لها وصل بوصل متسلسل.
- حساب استحقاقات الأساتذة بناءً على طريقة أجر كل أستاذ وطريقة تقسيم إيراد الدورة.
- تقارير شهرية، وتقرير لكل أستاذ، وتقرير بالأقساط المتبقية مع تصدير CSV وطباعة مباشرة.
- زر لإرسال تأكيد الدفعة عبر واتساب، جاهز للربط بمزوّد رسائل حقيقي لاحقاً.

كل المبالغ تُخزَّن كأعداد صحيحة حتى أتجنّب مشاكل الفواصل العشرية، كما أخزّن لقطة من سعر الدورة وتقسيمها وقت الاشتراك، فلو تغيّر السعر لاحقاً لا تتأثر التقارير القديمة.

## التقنيات

- Next.js 16 مع App Router وServer Actions، وReact 19 وTypeScript.
- Prisma 7 للتعامل مع قاعدة البيانات، وقاعدة MySQL.
- Tailwind CSS v4 لمكوّنات واجهة خفيفة بنيتها بنفسي بأسلوب shadcn بدون تبعيات إضافية.
- Zod للتحقق من المدخلات، وSonner للتنبيهات، وأيقونات lucide-react، وخط Cairo العربي.

## التشغيل

تحتاج Node.js وقاعدة MySQL شغّالة. بعدها:

```bash
npm install
cp .env.example .env
```

افتح ملف `.env` وعدّل `DATABASE_URL` ليطابق قاعدتك، ثم جهّز الجداول وشغّل المشروع:

```bash
npm run db:push
npm run db:seed   # اختياري، يملأ بيانات تجريبية عربية
npm run dev
```

التطبيق يعمل على `http://localhost:3000`.

للانتقال إلى الإنتاج يكفي تغيير `DATABASE_URL` إلى رابط قاعدة MySQL مستضافة، ثم `npm run build` و`npm run start`. طبقة الوصول للبيانات تعتمد على هذا المتغير فقط فلا حاجة لتعديل أي كود.

اسم المعهد ورمز العملة قابلان للتعديل من `lib/constants.ts`.
